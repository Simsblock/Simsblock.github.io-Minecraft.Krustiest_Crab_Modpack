[Text formatting Everywhere](https://modrinth.com/mod/text-formatting-everywhere) allows you to use colors in your text, like in the legacy formatting system.

---

## How To do it

Before writing text add `§#`, # being a number from 0-9 or r.

> 0 : Black \
> 1 : Blue \
> 2 : Green \
> 3 : Cyan \
> 4 : Red \
> 5 : Magenta \
> 6 : Orange \
> 7 : Light Gray \
> 8 : Dark Gray \
> 9 : Aquamarine \
> r : White (Standard color)
